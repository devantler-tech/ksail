## What is KSail?

Running Kubernetes usually means installing and wiring together kind or k3d, kubectl, Helm, a GitOps
engine and SOPS — and every distribution does it a little differently. KSail embeds those tools in a
single binary driven by one `ksail.yaml`, so the same commands create, update and delete a cluster
whether it runs in Docker on your laptop or on cloud infrastructure. It writes native configs such as
`kind.yaml` and Talos patches, so you can keep using the underlying tools with or without KSail.
